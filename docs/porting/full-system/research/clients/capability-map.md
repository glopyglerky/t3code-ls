# Client and platform capability map

Pinned upstream: `pingdotgg/t3code@28706aceb6fb3babf2cbae0dc0c3edd93b9b6d5f`.

This map records 30 capability families for a complete Rust implementation. It is a requirement inventory based on the inspected sources, not a claim that every screen or handler has been reviewed. The full source/review ledger is in `source-coverage.json`. The companion report explains the optimized stock baseline and proposed architecture.
